# Rep & Rest

Personal workout + sleep tracker, installable as an app (PWA).

- App: https://ammarzafri1136.github.io/daily-workout/
- Data is stored in a private Google Sheet through an Apps Script API. Every call needs the app key,
  which is kept only in Script Properties and on the owner's device — it is **not** in this repo.

Files here are generated from `src/App.html` of the tracker project by `tools/build_pages.py`.
